# Clicktrail

화면을 캡처하고 클릭 위치를 지정하면, 상대방이 직접 눌러 볼 수 있는 사용 설명서를 HTML 하나로 만듭니다.

## 바로 실행

`editor.html`을 크롬으로 열기 → **Load sample** → **Export clickable HTML** → 내려받은 HTML 열기.

## 내 화면으로 만들기

1. `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → 이 폴더 선택.
2. 설명할 사이트에서 확장 프로그램을 눌러 **Capture this screen**. 단축키는 **Alt+Shift+S**.
3. 실제 사이트에서 다음 동작을 수행하고 다시 캡처. **동작하기 전에 캡처하세요.**
4. 캡처를 마친 뒤 **Open walkthrough editor**에서 화면마다 클릭 위치와 설명 지정.
5. **Export clickable HTML**로 내보내 공유. 받는 사람은 설치 없이 브라우저에서 열 수 있습니다.

자동 클릭 녹화가 아닌 수동 단계 캡처 방식입니다. 재생 결과는 실제 사이트가 아닌 스크린샷 기반 체험입니다. 화면에 보이는 부분만 저장하며 단계당 클릭 위치는 하나입니다. 최대 30단계이고 이미지 크기에 따라 저장 한도에 먼저 도달할 수 있습니다. 캡처 중에는 편집기를 닫아 두세요.

캡처에 개인정보가 포함될 수 있습니다. 자동 가림 기능은 없으므로 공유 전 각 화면을 확인하세요. 서버나 API 키는 필요 없습니다.
